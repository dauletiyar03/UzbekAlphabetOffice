# O‘zbek alifbosi для Microsoft Office

Набор надстроек для настольных Word, Excel и PowerPoint в Windows. Он помогает вводить узбекские латинские буквы и вручную преобразовывать выделенный текст. В Word также работает автоматическое преобразование сочетаний клавиш.

## Установка готовой версии

1. Откройте **Releases** на странице GitHub и скачайте `YangiAlifboOffice-Setup.zip`.
2. Распакуйте архив в любую папку.
3. Закройте Word, Excel и PowerPoint.
4. Запустите `Install.cmd`. В окне Windows подтвердите доверие издателю **Yangi Alifbo**, если согласны установить надстройку.
5. Снова откройте приложения Office. Вкладка надстройки появится в тех приложениях, которые установлены на компьютере.

Чтобы удалить надстройки, закройте Office и запустите `Uninstall.cmd` из той же распакованной папки.

Установщик рассчитан на настольный Microsoft Office 2016 или новее и .NET Framework 4.8. Если Office сообщает об отсутствии VSTO Runtime, установите **Microsoft Visual Studio Tools for Office Runtime** и повторите установку.

## Сборка из исходников

Нужны Windows, Visual Studio с нагрузкой **Разработка Microsoft 365** (Office/VSTO) и .NET Framework 4.8 Developer Pack. Откройте `UzbekAlphabetOffice.sln` и выполните сборку. Для готового установочного архива запустите `scripts\Package-Release.ps1` в PowerShell из клона репозитория; результат появится в `artifacts\YangiAlifboOffice-Setup.zip`.

Локальные ключи подписи `.pfx` намеренно не хранятся в Git. Сценарий упаковки создаёт отдельный самоподписанный сертификат `Yangi Alifbo` в хранилище текущего пользователя Windows и включает в архив только его открытый сертификат. Установщик добавляет его в доверенные сертификаты Windows после явного подтверждения.

## Что делает каждая надстройка

- **Word:** автоматически преобразует введённые сочетания букв; кнопка на вкладке надстройки преобразует выделенный текст.
- **Excel:** преобразует текст в выделенных ячейках, оставляя числа и формулы без изменений.
- **PowerPoint:** преобразует выделенный текст в текстовом поле. Office может объединить форматирование символов внутри преобразуемого фрагмента.

Надстройки запускаются внутри настольного Office. Веб-версии Office не поддерживаются.
